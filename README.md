## 💡 Fancy Fonts vs Unicode Text

Many online "fancy fonts" aren't actually downloadable fonts.

Instead, text generators can use Unicode characters from different Unicode character ranges to create text that visually appears in different styles.

This makes the resulting text copyable and usable across platforms that support those Unicode characters.
